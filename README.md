# Site institucional para clínica estética

Projeto demonstrativo de uma página institucional para clínica de estética facial e corporal.

## O que este projeto mostra

- Hero com proposta clara
- Serviços com duração, indicação e orientação comercial
- Foto de tratamento no primeiro impacto
- Estrutura para apresentar diferenciais, localização e horário
- Botão de WhatsApp
- Seção de benefícios
- Depoimentos
- FAQ
- Formulário que gera mensagem pronta para WhatsApp
- Layout responsivo

## Para quem serve

Este modelo pode ser adaptado para:

- Clínicas
- Salões de beleza
- Barbearias
- Oficinas
- Restaurantes
- Prestadores de serviço
- Lojas locais

## Como funciona

O usuário navega pela página, entende os tratamentos, conhece a equipe, vê informações de localização e pode entrar em contato pelo botão de WhatsApp. No formulário final, ele informa nome, serviço e telefone. O JavaScript gera uma mensagem pronta e abre o WhatsApp com o texto preenchido.

## Diferencial comercial

Este exemplo foi pensado para ser adaptável. Ele não representa uma clínica real específica; serve como modelo de apresentação para clínicas, profissionais de estética e pequenos negócios que precisam captar contatos com mais confiança.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como rodar

Abra o arquivo `index.html` no navegador.

## Como publicar no GitHub Pages

1. Crie um repositório chamado `site-clinica-estetica`.
2. Envie os arquivos `index.html`, `style.css`, `script.js` e `README.md`.
3. No GitHub, vá em `Settings > Pages`.
4. Em `Branch`, selecione `main` e a pasta `/root`.
5. Salve e aguarde o link publicado.
